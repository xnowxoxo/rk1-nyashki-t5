# РК1 · Трек 5 · Множество Мандельброта

Хакатон PARAM BILIM Speedup Challenge, РК1, раунд 2.
Картинка 4096 × 4096, до 2000 итераций на точку, область [−2; 1] × [−1,5; 1,5].

Команда:
- Шамиль Н. — MPI (`src/mpi.c`)
- __________ — OpenMP (`src/omp.c`)

## Структура

```
src/      mandel.h  seq.c  omp.c  mpi.c
slurm/    omp.sbatch  mpi.sbatch
scripts/  analyze.py
logs/     *.out из Slurm, без правок
plots/    speedup.png  efficiency.png
```

`mandel.h` общий для всех версий: параметры и функция расчёта одной точки. Поэтому результат во всех версиях совпадает побитово.

## Проверка корректности

Каждая версия считает контрольную сумму картинки с весом позиции, Σ img[i]·(i+1). Так ловятся и неверные значения, и строки, собранные не на своё место.

`seq` при первом запуске записывает эталон в `ref_4096.txt`. `omp` и `mpi` сверяются с ним и печатают `CHECK: OK`/`FAIL` (в строке вывода — `OK`/`FAIL`).

Формат вывода: `version;p;time_s;CHECK`. Строки с `#` служебные, `#detail` у MPI показывает время счёта самого быстрого и самого медленного процесса и время сбора.

## Декомпозиция в MPI

Строки раздаются циклически: процесс r считает строки r, r+p, r+2p, … Тяжёлые строки идут через середину картинки подряд, и при раздаче блоками почти вся работа досталась бы средним процессам. При циклической раздаче у каждого процесса есть и лёгкие, и тяжёлые строки.

Каждый процесс получает N/p строк, первые N mod p процессов — на одну больше. Rank 0 собирает куски через `MPI_Gatherv` (counts и displs по этим размерам) и расставляет строки по местам.

Для сравнения есть блочная раздача: `MANDEL_DIST=block`.

## Как воспроизвести на PARAM BILIM

```bash
# на bilim-master (на вычислительных узлах нет заголовков C)
module load intel/mpi/2021.14
make

mkdir -p logs
sbatch slurm/mpi.sbatch      # seq ×3 + MPI 1..64 процесса ×3, 2 узла
sbatch slurm/omp.sbatch      # OpenMP 1..32 потока, static / dynamic,16 / guided
squeue -u $USER

# когда оба задания закончатся
python3 scripts/analyze.py   # results.md + plots/
```

Для быстрой проверки на маленькой картинке: `MANDEL_N=512 ./bin/seq`, потом `MANDEL_N=512 ...` для остальных версий.

## Окружение

Заполнить по выводу на узле: `lscpu`, `gcc --version`, `mpicc -v` / `mpirun --version`.
